# 선형 회귀 모델

## 머신 러닝
- AI(Artificial Intelligence) : 인간의 지능적인 행동을 컴퓨터로 구현하는 학문. 기계가 스스로 생각하고 판단하게 만드는 것을 목표로 한다.
- 머신러닝 : 데이터로 부터 스스로 학습하는 AI 기술로, 사람이 일일이 규칙을 알려주지 않아도 데이터를 통해 패턴을 학습하여 예측이나 분류를 할 수 있게 된다. 규칙을 직접 프로그래밍하지 않고, 데이터로부터 규칙을 배우는 것을 목표로 한다.
  - 지도 학습 : 입력 데이터와 그에 대응하는 정답이 함께 주어지는 데이터를 이용해 학습하는 방식이다. 모델이 입력값을 통해 올바른 출력을 예측하도록 정답을 보면서 학습한다.
  - 비지도 학습 : 정답이 없는 데이터를 이용해 데이터의 숨은 구조나 패턴을 스스로 발견하는 방식이다. 데이터 간의 유사성을 기반으로 그룹을 나누거나, 차원을 축소해 중요한 특징을 찾아낸다.
  - 강화 학습 : 에이전트가 환경 속에서 행동을 수행하고, 그 결과로 보상을 받으며 점점 더 나은 행동 전략을 학습하는 방식이다. 즉, 시행착오를 통한 학습니다.
## 선형 회귀
- 선형 회귀는 입력 변수와 출력 변수 사이의 관계를 선형으로 모델링하여 예측하는 알고리즘이다.
- 기본 수식 : y = wx + b (x = 입력값, y = 예측값, w = 기울기(가중치), b = 절편(편향))
- 다중 선형 회귀 : 입력 변수가 하나 이상, 여러 특성을 동시에 고려
    - 수식 : y = w1x1 + w2x2 + w3x3 + ... + b

    -> 기울기 w와 절편 b를 데이터에 맞게 조정하는 것이 목표
- 가설 : 우리가 예측에 사용할 직선의 방정식을 지칭하는 용어
- 비용 함수 : 가장 잘 맞는 직선을 찾기 위해서는 실제값 yi와 ŷi 차이를 최소화 해야 한다. 이 차이를 측정하는 함수가 비용 함수(Cost Function) 또는 손실 함수(Loss Function)이다. 보통 평균제곱오차(MSE, Mean Squared Error)를 사용하여 계산한다.
- 평균제곱오차(MSE, Mean Squared Error) : 모델의 예측값과 실제 정답과의 차이를 제곱하여 계산하는 방법이다. 양수 오차와 음수 오차의 상쇄를 막고 큰 오차일 수록 페널치를 부여하기 위해 제곱을 한다. 제곱의 총합을 구한 뒤 평균을 구한다.
- 최소 제곱법(MLS, ) : 예측 모델에서 비용을 최소화하는 w와 b를 찾는 원리
- 경사 하강법 : 반복적인 계산을 통해 점진적으로 최적의 파라미터를 찾아가는 방법이다. 2차 방정식인 비용 함수에서 가장 작은 값을 찾기 위해 특정 점으로 부터 점진적으로 내려가며 기울기가 0이 되는 점을 찾는다.
    - 기울기 : 비용 함수의 각 파라미터를 미분하여 구한다.
    - 학습률 : 한 번에 얼마나 이동할지를 결정하는 보폭(step size)이다.
    - 기울기의 반대 방향으로 학습률만큼 이동하여 파라미터를 업데이트 한다. 이 과정을 비용 함수의 값이 더 이상 줄어들지 않을 때까지 반복한다.
- 정규 방정식 : 수학적인 공식을 이용해 단 한 번의 계산으로 최적의 파라미터를 직접 찾는 해석적 방법이다. 한 번에 계산할 수 있다는 장점이 있지만 특성 수가 많으면 계산이 복잡해지고, 계산 식의 행렬이 역행렬이 존재하지 않는 경우 사용할 수 없다.
