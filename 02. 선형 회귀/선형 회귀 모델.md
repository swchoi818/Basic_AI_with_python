# 선형 회귀 모델

## 머신 러닝
- AI(Artificial Intelligence) : 인간의 지능적인 행동을 컴퓨터로 구현하는 학문. 기계가 스스로 생각하고 판단하게 만드는 것을 목표로 한다.
- 머신러닝 : 데이터로 부터 스스로 학습하는 AI 기술로, 사람이 일일이 규칙을 알려주지 않아도 데이터를 통해 패턴을 학습하여 예측이나 분류를 할 수 있게 된다. 규칙을 직접 프로그래밍하지 않고, 데이터로부터 규칙을 배우는 것을 목표로 한다.
  - 지도 학습 : 입력 데이터와 그에 대응하는 정답이 함께 주어지는 데이터를 이용해 학습하는 방식이다. 모델이 입력값을 통해 올바른 출력을 예측하도록 정답을 보면서 학습한다.
  - 비지도 학습 : 정답이 없는 데이터를 이용해 데이터의 숨은 구조나 패턴을 스스로 발견하는 방식이다. 데이터 간의 유사성을 기반으로 그룹을 나누거나, 차원을 축소해 중요한 특징을 찾아낸다.
  - 강화 학습 : 에이전트가 환경 속에서 행동을 수행하고, 그 결과로 보상을 받으며 점점 더 나은 행동 전략을 학습하는 방식이다. 즉, 시행착오를 통한 학습니다.
## 선형 회귀
- 선형 회귀는 입력 변수와 출력 변수 사이의 관계를 선형으로 모델링하여 예측하는 알고리즘이다.
- 기본 수식 : y = wx + b (x = 입력값, y = 예측값, w = 기울기(가중치), b = 절편(편향)) 
    -> 기울기 w와 절편 b를 데이터에 맞게 조정하는 것이 목표
